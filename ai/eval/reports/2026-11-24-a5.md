## Caveats (read first)
1. **Ceiling effect on extraction.** Gold is generated from the same structured source as the CV text, so the CVs are clean and the 1.00 scores mean "no regressions on clean synthetic CVs", not "production-ready on real, messy CVs". Real PDF-extracted text needs a separate check.
2. **Judge = same model as the scorer** (D-AI-LABELS: no human labels; only one model is configured, so `LLM_MODEL_HEAVY` was not used). Self-preference bias is possible, so fit numbers are relative. Sanity check: judge mean vs my independent draft labels Spearman 0.951 (n=50).
3. One run per LLM call for extraction/fit/red-team (no sampling control on this API). Judge: 3 runs averaged.
4. Red-team CVs kept their protected-attribute lines in the input (production redaction would drop them first), so the leak test is stricter than production.

## 6. Prompt changes made (`backend/src/ai/PROMPT_CHANGELOG.md`)
- `cv_extract` 1.0 → 1.1 (section 1).
- `job_rerank` 1.0 → 1.1: "return every candidate when there are 10 or fewer; rank poor fits last". In my test 1.0 already returned 5/5 for 3 profiles (the backend worker saw 2/5 on a different set); 1.1 also gives 5/5 with valid ids. The change is for robustness; the app must still append any candidate the model omits and never trust the count.
- `cv_feedback` 1.0 → 1.1: explicit rubric → `area` mapping after one invalid enum value at 1.0; 4/4 valid at 1.1 (n is small).
- Rewrite checks on the assist set: bullet count/order preserved 4/4, no invented numbers 8/8 (summary + bullets). The full rubric and judge calibration (A7) are not done.

## 7. Decision
- **Ship behind `AI_ENABLED`: parse (cv_extract 1.1), job-skills suggest, fit (hybrid).** All quality and safety gates pass and the deterministic gates are 100 %. Keep the one-repair retry and the fallbacks.
- **Tune the UX (latency), not the prompts:** every p50/p95 target is missed on this model. Compute fit in the background and cache it (never block the page), show a spinner for parse, set timeouts to at least 60 s.
- **Faster model for assist and rerank (recommended):** summary, bullets, skills, feedback and rerank are interactive and take 6–36 s. Ask the owner for a non-reasoning (or reasoning-off) model, as a second env pair such as `LLM_MODEL_FAST` for assist + rerank, keeping the current model for parse and fit. If none exists, ship assist with loading states and a cancel option.
- **Not done / next:** real messy PDF text, job-text injection, rerank nDCG (no relevance labels; `rec_labels.csv` is a draft), repeat-run variance of fit_assess, cost in dollars (needs `AI_PRICE_TABLE`), `LLM_MODEL_HEAVY` as an independent judge.
